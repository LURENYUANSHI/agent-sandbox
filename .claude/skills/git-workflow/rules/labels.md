# GitHub Label System

> **IMPORTANT**: Only use the labels listed below.

## Status Labels — Issue/PR Lifecycle

| Label             | Description                               |
| ----------------- | ----------------------------------------- |
| `status::backlog` | Recorded but not scheduled                |
| `status::planned` | Scheduled and ready to implement          |
| `status::doing`   | Currently being implemented               |
| `status::review`  | PR created, awaiting review               |
| `status::done`    | Completed and merged                      |
| `status::blocked` | Blocked by external dependency            |

## Type Labels — Issue Classification

| Label            | Description                           |
| ---------------- | ------------------------------------- |
| `type::feature`  | New feature or enhancement            |
| `type::bug`      | Bug fix                               |
| `type::chore`    | Maintenance task (deps, config, etc.) |
| `type::docs`     | Documentation update                  |
| `type::refactor` | Code refactoring                      |
| `type::test`     | Test addition or modification         |

## Priority Labels

| Label          | Description                |
| -------------- | -------------------------- |
| `priority::p0` | Critical — Drop everything |
| `priority::p1` | High priority              |
| `priority::p2` | Normal priority            |
| `priority::p3` | Low priority               |

## Area Labels — Affected Components

| Label              | Description                    |
| ------------------ | ------------------------------ |
| `area::sandbox`    | Core sandbox runtime           |
| `area::policy`     | Policy engine                  |
| `area::trace`      | Trace recording/replay         |
| `area::executor`   | Action executors               |
| `area::api`        | REST API / WebSocket           |
| `area::cli`        | CLI interface                  |
| `area::web`        | React dashboard                |
| `area::infra`      | Infrastructure/DevOps/Docker   |

## Agent Labels

| Label            | Description                |
| ---------------- | -------------------------- |
| `agent::claude`  | Implemented by Claude Code |
| `agent::human`   | Requires human work        |

## Special Labels

| Label               | Description                        |
| ------------------- | ---------------------------------- |
| `automated`         | Auto-generated by pipeline         |
| `overnight-build`   | Part of overnight autonomous build |
| `good-first-issue`  | Good for newcomers                 |
